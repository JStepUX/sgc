# 2026-07

## 2026-07-04 — Plug-in brains: the knowledge axis (Atlantis packs, lexical retrieval)

A chat can now mount **brains** — `sgc-brain/1` JSON packs of document chunks
compiled offline by the sibling Atlantis repo and retrieved at turn time by the
same deterministic engine style as Grepory: TF-IDF cosine over a **union index**
(one shared IDF across all mounted packs, spec D3), client-side, 0 ms, 0 tokens,
**no model anywhere at runtime**. Knowledge is a separate axis from memory — the
three memory tiers are untouched, and an isolation regression pins `grepResults`
byte-identical with and without mounts. Packs carry lexical fields only (text,
summary, topics, and hand-editable `aliases` — the deterministic synonym bridge
across the author gap); Atlantis's Chroma/MiniLM embeddings never cross the
contract. Embedding retrieval is Phase 2b, a separate raise that must beat this
baseline on the brain probes first.

- **Atlantis side**: new `python -m atlantis export` maps active chunk
  frontmatter onto the pack contract (aliases flattened keys+values, first
  fence-pair-only parsing so bodies may contain `---`). Ingest now stamps the
  classifier `backend` into `index.json` so export derives `source.stub` from
  disk instead of trusting an operator flag (Core Value #3). `tests/test_export.py`
  covers contract validity, determinism, status filtering, and stub provenance.
- **Prompt tier**: PERSONA KNOWLEDGE renders between retrieved history and
  linked pages — an always-present per-brain digest (name, doc titles, primary
  topics, capped at `BRAIN_DIGEST_CHAR_CAP`) even on zero-hit turns, so a
  mounted brain is never invisible (D10), then the top fragments tagged
  `[brain · title]`. The WHOLE tier — digest included, it's pack-author prose
  too — sits inside one data-not-instructions fence (position pinned by test,
  hardened per review). Real prompt only — `estimateNaiveContextTokens` never
  sees it (D7), keeping Context Savings honest.
- **Mounting is per-chat curation** (D6): picker + pack import in the
  Begin-again dialog, MOUNTED BRAINS section in the memory panel for mid-chat
  mount/unmount, `chat_brains` bindings in SQLite cascading both directions.
  Packs live as files beside the DB (`<data>/brains/<id>.json`,
  `SGC_BRAINS_DIR` overrides), imported via `POST /api/brains` (validated,
  atomic write, overwrite-by-id; the JSON body limit is raised for this one
  route). Re-spin uses CURRENT mounts, like memories/persona (D8). Stub-built
  packs show a "model-free build" badge (D9).
- **Eval**: `brain-eval.test.ts` runs the probe-ledger discipline over
  `searchBrains` + the committed fixture pack (3 stub-built docs, 8 chunks,
  hand-authored aliases): direct-term recall, **alias-bridge recall with a
  structural zero-shared-stems check** (query stems must live in aliases only),
  false-positive guard, and known-gap synonymy probes that fail loudly if a
  non-lexical bridge ever closes them. Measured at creation: recall@3 1.000,
  MRR 1.000 over 8 pass-probes; ratchets at 0.90.
- **The anti-god-object ratchet fired on four files** during the build and was
  obeyed, not raised: brains routes → `server/brains-routes.ts`, mount bindings
  → `server/db-brains.ts`, the response parser → `lib/turn-parser.ts`
  (re-exported from prompt.ts), and the mount axis → `hooks/useBrainMounts.ts`
  (+ `replayEntry` joined its fellow rehydration parsers in `lib/turn-data.ts`).
- Inspector gains a Knowledge line + per-fragment provenance cards
  (`TurnData.knowledgeDetails`, optional for old turns).
- Spec archived at `docs/ignored/plugin-brains-spec.yaml`.

## 2026-07-03 — Porter stemming in the shared tokenizer (inflection gap closed)

`tokenize()` now ends in Porter stemming, so inflection variants collide
("needles"/"needle", "painted"/"painting" → one stem) — closing the
regular-inflection half of the documented synonymy gap with pure suffix
arithmetic. No model, no data, no drift surface: the npm `stemmer` package
(pinned 2.0.1, dev-dep like chrono-node) wrapped in a new `lib/stem.ts` so the
engine's import surface stays ours. One change upgrades every consumer of the
shared tokenizer: the memory grep, the (future) brain union index, and the
spontaneity slack detector.

- **Eval ledger stays honest in both directions** — new `inflection` fixture +
  probe category: plural and verb-form pass-probes *verified to miss against
  the pre-stem tokenizer* (stash-check) and hit at rank 1 after; one new
  known-gap probe pins what Porter can't reach (irregular "ran" ↛ "running").
  Re-measured: recall@3 1.000, MRR 0.969 over 16 pass-probes (ratchets stay
  0.90). The one rank slip is documented at the measured comment.
- **A synonymy probe flipped and was repaired, not promoted**: query "approval"
  collided with planted "approved" (both → `approv`) — an inflection match
  masquerading as a synonym bridge. Query redesigned to "decision"; the
  boss-for-manager gap stays known-gap. Rule tightened in AGENTS.md:
  zero-shared-vocabulary is now measured on stems.
- **Slack detector inherits stemming intentionally** (spec D4), threshold
  untouched. Measured against the 9 real dev chats (290 windows): mean
  similarity 0.294 → 0.338, firings at 0.3 up 135 → 200. Noted in the
  spontaneity README's calibration caveat for the separate retune it already
  owns — the provisional 0.3 sits in the fat of the distribution.
- No migration: there is no stored index; scores shift deterministically at the
  next search. D2 stopword edge ("makes" → "make" survives) pinned in tests.
- Spec archived at `docs/ignored/stemming-spec.yaml`.

Small local models sometimes truncate the trailing `<turn-summary>` block at
the token cap or malform its JSON; the raw block then leaked into the visible
reply (and the grep corpus) and had to be hand-deleted. `parseTurnResponse`
(`lib/prompt.ts`) now treats any *JSON-bearing* tagged block (`{` after the
tag — the same rule `stripStreamingMeta` streams by, so prose mentions of the
tag stay visible) as a block: it is stripped from display unconditionally and
the summary is salvaged with deterministic string surgery — strict parse first,
then code-fence unwrap, `completeJson` (close open string, drop dangling comma,
close open brackets), and a cut-back-to-last-structural-boundary retry for
mid-key truncation. No model in the loop; streaming and finalized views now
agree.

- **Legacy rows self-clean at load**: the three replay paths in
  `hooks/useChatSession.ts` (hydration, chat switch, memory-editor resync) now
  share one `replayEntry` that routes persisted assistant content back through
  `parseTurnResponse`, so pre-fix rows render — and grep — clean. The DB row is
  untouched; it heals on the turn's next edit/save.
- Side fix that fell out of unifying replay: `resyncLiveChatLog` used to
  rebuild `chatLog` without summaries, silently starving the distilled summary
  buffer after a memory-editor mutation. It now rehydrates them.
- 4 pinned parser expectations deliberately updated + 8 new bork-mode tests in
  `prompt.test.ts`; verified live against the wild leaked rows (both now render
  clean, adjacent prose byte-identical).

## 2026-07-03 — Client split: god object → root + hooks + components (+ a ratchet)

`SalienceGatedCognition.tsx` had grown to 2,244 lines — nine embedded `memo()`
components plus a ~1,130-line root holding 31 `useState`s. Behavior-preserving
split, no thesis surface touched (retrieval stays `lib/`, still pure math):

- **Components** (nine files → `components/`): `AuroraBackground`, `PhaseBar`,
  `ProviderChip`, `MemoryPanel`, `TurnInspector`, `TokenChart`,
  `AssistantMessage`, `UserPill`, `Composer` (+ shared `rail-styles.ts`).
- **Hooks** (new `hooks/` dir, one per state axis): `useChatSession`
  (persistence/hydration/memories/persona), `useTurnRunner` (the live turn —
  `processInput` moved verbatim), `useResponseEditor` (edit/re-spin),
  `useProvider`, `useAuroraPulse`, `useRailCollapse`. Deliberately namespaces
  over ONE shared session, not isolated stores — `useChatSession` exposes its
  setters to the sibling hooks.
- **Shared types** → `lib/turn-data.ts` (TurnData + the tolerant
  inspector_json rehydration parsers, now unit-tested) and `lib/provider.ts`.
- The root is now a ~270-line composition root: hook wiring + modal flags +
  JSX only.
- **The anti-god-object ratchet**: `src/architecture.test.ts` enforces
  per-file line budgets over `src/` + `electron/` (default 500; four
  grandfathered exceptions) and fails when a budget goes stale high — a failure
  means "split the file", never "raise the budget". Required an
  `eslint.config.js` block for top-level `src/*.ts` (no TS parser covered them
  before).
- Doc sweep: every spec/comment that anchored future work inside the old
  monolith (`plugin-brains-spec`, `deliberate-recall-spec`,
  `setup-process-review-2026-07`, AGENTS.md, spontaneity README, `types.ts`,
  eval mirror comment, pre-commit-qa skill) re-pointed at the new layout.
  Split spec archived at `docs/ignored/client-split-spec.yaml`.
- Verified: 254 tests, 3 tsconfigs, lint, plus a live LOCAL-provider turn
  end-to-end (grep fired, spontaneity read recorded, summary parsed, persisted,
  rehydrated on reload).
